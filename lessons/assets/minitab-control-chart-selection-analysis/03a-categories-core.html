Minitab’s six control-chart categories

The structure below mirrors the Minitab desktop menu: Stat > Control Charts.

Variables Charts for Subgroups Variables Charts for Individuals Attributes Charts Time-Weighted Charts Multivariate Charts Rare Event Charts

Category 1

Variables Charts for Subgroups

Continuous measurements collected in rational subgroups

Use when several measurements are collected under nearly identical short-term conditions. The subgroup design is part of the analysis—not merely a worksheet format.

Xbar-R

Best for: monitoring the subgroup mean and within-subgroup range when subgroup size is generally 2–8.

Stat > Control Charts > Variables Charts for Subgroups > Xbar-R
  • Example: five thickness readings every hour.
  • Read the R chart first, then the Xbar chart.
  • Use time-ordered rational subgroups.
Step-by-step Minitab setup
  1. Place measurements in one column with a subgroup ID column, or place each subgroup across one row.
  2. Open the menu path above.
  3. Select the appropriate data arrangement.
  4. Enter the measurement column(s) and subgroup IDs or subgroup size.
  5. Select Xbar-R Options > Tests to add company-approved special-cause tests.
  6. Select OK. Evaluate R before Xbar.
Use another chart when

Use Xbar-S for subgroup sizes of 9 or more. Use I-MR-R/S when each subgroup is a distinct batch or part with a consistent within-item variation source.

Xbar-S

Best for: monitoring mean and standard deviation with larger subgroups, generally 9 or more.

Stat > Control Charts > Variables Charts for Subgroups > Xbar-S
  • Example: 12 hardness readings per plate.
  • S uses every observation and is more efficient than range for larger subgroups.
  • Read S first, then Xbar.
Step-by-step Minitab setup
  1. Arrange the subgroup observations in columns plus subgroup ID, or across rows.
  2. Open Xbar-S.
  3. Specify variables and subgroup structure.
  4. Use Xbar-S Options for tests, stages, and historical parameters.
  5. Create the chart and investigate S-chart signals before mean signals.
Use another chart when

Use Xbar-R for smaller subgroups. Use I-MR-R/S for repeated measurements within distinct batches or parts.

I-MR-R/S (Between/Within)

Best for: separating variation within each distinct part or batch from variation between consecutive parts or batches.

Stat > Control Charts > Variables Charts for Subgroups > I-MR-R/S (Between/Within)
  • Produces three panels: I, MR, and either R or S.
  • R/S measures within-subgroup variation.
  • MR measures between-subgroup variation using consecutive subgroup means.
Step-by-step Minitab setup
  1. Ensure each subgroup represents a distinct batch, part, coil, or repeated-measure unit.
  2. Arrange one row per subgroup or use one measurement column plus subgroup IDs.
  3. Open the path above and enter the data structure.
  4. Use I-MR-R/S Options for tests, stages, and known parameters.
  5. Interpret R/S first, MR second, I last.
Steel example

Five gauge readings across each coil: R/S assesses within-coil uniformity, MR assesses coil-to-coil changes in average gauge, and I assesses the sequence of coil means.

Xbar

Best for: monitoring subgroup means only when dispersion is already being evaluated separately.

Stat > Control Charts > Variables Charts for Subgroups > Xbar
Step-by-step Minitab setup
  1. Enter subgroup measurements and IDs.
  2. Open Xbar.
  3. Specify the variables and subgroup structure.
  4. Use Xbar Options for tests or historical parameters.
  5. Do not interpret the chart unless short-term variation is stable.

For routine work, Xbar-R or Xbar-S is usually safer because it displays the companion variation chart.

R

Best for: monitoring within-subgroup range for smaller subgroups.

Stat > Control Charts > Variables Charts for Subgroups > R
Step-by-step Minitab setup
  1. Provide at least two observations per subgroup.
  2. Open R.
  3. Enter variables and subgroup IDs or size.
  4. Create the chart and investigate sudden increases, decreases, trends, or nonrandom patterns in range.

R compares values inside the same subgroup. It is not the same as MR, which compares consecutive time points.

S

Best for: monitoring within-subgroup standard deviation for larger subgroups.

Stat > Control Charts > Variables Charts for Subgroups > S
Step-by-step Minitab setup
  1. Use larger subgroups with enough observations to estimate standard deviation reliably.
  2. Open S.
  3. Specify the variables and subgroup structure.
  4. Interpret changes in within-subgroup dispersion.

Zone

Best for: detecting sustained mean shifts through cumulative scores assigned to sigma zones.

Stat > Control Charts > Variables Charts for Subgroups > Zone
Step-by-step Minitab setup
  1. Prepare subgrouped continuous data.
  2. Open Zone.
  3. Enter variables and subgroup IDs or size.
  4. Review cumulative scores and signals; the chart does not use the standard special-cause tests menu.
  5. Investigate sequences accumulating on one side of the center line.

Consider EWMA or CUSUM when you require a designed sensitivity to a specific small shift.

Category 2

Variables Charts for Individuals

One continuous observation per time point

Use when subgrouping is impractical, production volume is low, measurement is destructive or expensive, or only one result exists per coil, heat, batch, or time period.

I-MR

Best for: monitoring individual continuous values and their short-term moving ranges.

Stat > Control Charts > Variables Charts for Individuals > I-MR
  • Example: one exit temperature per coil.
  • Read MR first, then I.
  • Do not average independent observations merely to force an Xbar chart.
Step-by-step Minitab setup
  1. Place the measurement in one column, sorted chronologically.
  2. Open I-MR.
  3. Enter the variable column.
  4. Use I-MR Options for tests, stages, and historical mean or standard deviation.
  5. Create the chart. Investigate MR signals before I-chart signals.

Z-MR

Best for: short-run monitoring across products, sizes, grades, or targets with different means and standard deviations.

Stat > Control Charts > Variables Charts for Individuals > Z-MR
Step-by-step Minitab setup
  1. Place results in one column and product/run identifiers in another.
  2. Provide or estimate a mean and standard deviation for each run or product.
  3. Open Z-MR and enter the observations plus identifiers.
  4. Review standardized Z values and moving ranges.
  5. Confirm that product-specific reference values are defensible before interpreting signals.

Do not mix unlike products on a conventional I-MR chart without standardization.

Individuals

Best for: monitoring process location only for individual observations.

Stat > Control Charts > Variables Charts for Individuals > Individuals
Step-by-step Minitab setup
  1. Place time-ordered values in one column.
  2. Open Individuals.
  3. Enter the variable.
  4. Use Individuals Options for tests or known parameters.
  5. Interpret only after variation has been established separately.

I-MR is normally preferred because it includes the moving-range companion chart.

Moving Range

Best for: monitoring short-term variation between consecutive individual observations.

Stat > Control Charts > Variables Charts for Individuals > Moving Range
Step-by-step Minitab setup
  1. Place time-ordered individual values in one column.
  2. Open Moving Range.
  3. Enter the variable and choose the moving-range length where appropriate.
  4. Interpret unusual jumps between consecutive observations.

MR versus R: MR compares adjacent time points; R compares multiple values within the same subgroup.

Category 3

Attributes Charts

Counts of defectives or defects

First determine whether every unit is classified once as defective/nondefective, or whether you count multiple defects on each unit. Then determine whether sample size or inspection opportunity is constant.

P

Best for: proportion defective when subgroup sizes may vary.

Stat > Control Charts > Attributes Charts > P
Step-by-step Minitab setup
  1. Create a column for number defective and a column for number inspected.
  2. Open P.
  3. Enter the defectives column and subgroup sizes.
  4. Use P Chart Options for tests, stages, or historical proportion.
  5. Interpret changing limits correctly when sample size varies.

NP

Best for: number defective when the same number of units is inspected each period.

Stat > Control Charts > Attributes Charts > NP
Step-by-step Minitab setup
  1. Use one column containing the count defective for each subgroup.
  2. Confirm a constant sample size.
  3. Open NP, enter the count column and subgroup size.
  4. Interpret the plotted count of defective units.

Use P when sample size varies.

Laney P′

Best for: proportion defective with overdispersion or underdispersion relative to the binomial model.

Stat > Control Charts > Attributes Charts > Laney P′
Step-by-step Minitab setup
  1. First verify that the response is defective/nondefective.
  2. Provide defectives and sample sizes as for a P chart.
  3. Open Laney P′.
  4. Review the adjusted limits and the dispersion adjustment.
  5. Investigate process structure before treating Laney adjustment as a substitute for understanding the variation.

U

Best for: defects per unit when inspection opportunity or sample size varies.

Stat > Control Charts > Attributes Charts > U
Step-by-step Minitab setup
  1. Create a defects column and an opportunity/sample-size column.
  2. Open U.
  3. Enter defects and subgroup sizes.
  4. Use U Chart Options for tests, stages, and historical defect rate.
  5. Interpret the plotted defects per unit and varying limits.

C

Best for: number of defects when the inspection opportunity is constant.

Stat > Control Charts > Attributes Charts > C
Step-by-step Minitab setup
  1. Confirm every subgroup represents the same area, length, time, or number of units inspected.
  2. Enter one column containing defect counts.
  3. Open C and enter the count column.
  4. Interpret changes in the number of defects.

Use U when opportunity varies.

Laney U′

Best for: defects per unit with overdispersion or underdispersion relative to the Poisson model.

Stat > Control Charts > Attributes Charts > Laney U′
Step-by-step Minitab setup
  1. Provide defects and opportunity/sample-size columns.
  2. Open Laney U′.
  3. Enter the columns as for a U chart.
  4. Review the adjusted limits and dispersion adjustment.
  5. Investigate clustering, mixed processes, and other structural sources of excess variation.
