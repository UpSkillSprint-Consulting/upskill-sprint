Common mistakes and software traps

Selection error: using P for defects.A P chart counts defective units, not multiple defects. Use C/U/Laney U′ for defects.
Subgroup error: grouping unrelated observations.A subgroup should represent short-term common conditions, not a convenient set of five rows.
Interpretation error: reading Xbar before R or S.Unstable variation compromises the location-chart limits.
Software error: entering sample size as the number defective.For P and U charts, verify the response and opportunity columns are assigned to the correct boxes.
Limit error: drawing specification limits as control limits.Specifications come from design or customer requirements; control limits come from process behavior.
Chronology error: sorting values from low to high.Control charts require production order. Sorting by magnitude destroys the time pattern.
Phase I error: deleting every red point.Exclude a point only after identifying and documenting a credible special cause.
Mixed-product error: placing unlike products on one I-MR chart.Use separate charts, stages, or a Z-MR short-run approach with validated product targets.
False-alarm error: turning on every test automatically.Additional tests increase sensitivity and the chance of false signals. Follow a documented monitoring plan.
Capability error: calculating Cpk on an unstable process.Capability estimates are unreliable when the process distribution changes over time.

Practice activity

Choose the correct chart for a surface-inspection process

Each shift, an inspector records the number of visible surface defects found on coils. The inspected surface area changes from shift to shift because coil lengths and widths vary. One coil may contain several defects.

Your task: select the chart, state the required worksheet columns, provide the full Minitab navigation path, and explain why a C chart would be inappropriate.

Correct chart: U chart.

Why: the response is a count of defects, multiple defects can occur on one coil, and inspection opportunity varies. The U chart standardizes the count as defects per unit of opportunity.

Worksheet: one column for defect count and one column for inspected surface area or another defensible opportunity measure.

Stat > Control Charts > Attributes Charts > U

A C chart is inappropriate because it assumes constant inspection opportunity. Laney U′ should be considered only after assessing whether overdispersion or underdispersion makes the conventional U chart misleading.

Mini quiz

1. You measure one Charpy average per coil. Which standard chart is the best starting point?

I-MR is appropriate because the response is continuous and there is one observation per coil.

2. Which statement correctly distinguishes an R chart from an MR chart?

R uses the maximum minus minimum within one subgroup. MR uses the absolute difference between consecutive values—or subgroup means in I-MR-R/S.

3. You inspect a different number of pipes each day and record how many are rejected. Which chart should you use?

P charts the proportion defective and accommodates varying sample sizes.

4. Which chart is designed to monitor exact elapsed time between rare events?

T charts use continuous elapsed time or exact date-time information. G charts use discrete opportunities or whole-day spacing.

5. An Xbar-R chart shows an out-of-control R chart but an apparently stable Xbar chart. What should you do first?

Variation must be stable before the Xbar chart can be interpreted reliably. Investigate and document the variation signals first.
