Universal step-by-step Minitab control-chart workflow

Use this procedure regardless of chart family. The menu selection changes; the analytical discipline does not.

Define the process question

State the process, quality characteristic, unit, sampling frequency, subgroup logic, and action you will take after a signal.

Verify the measurement system

Confirm calibration, repeatability, reproducibility, resolution, and consistent defect definitions. A control chart cannot repair unreliable measurement.

Preserve chronological order

Sort from oldest to newest. Do not sort by value. Include time, coil, heat, batch, shift, or sequence identifiers for investigation.

Choose rational subgroups

Within-subgroup observations should share nearly identical short-term conditions. Avoid subgroups that mix shifts, grades, machines, or long time spans unless that is intentional.

Select the Minitab category and chart

Choose Stat > Control Charts, then the category that matches the data-generating process.

Complete the main dialog

Enter the response variable(s), subgroup IDs or sizes, defect counts and opportunities, product identifiers, or event dates as required.

Set options deliberately

Use chart-specific Options for tests, stages, historical parameters, estimate methods, and storage. Minitab uses only Test 1 by default for many charts; add tests only when justified by your standard and false-alarm tolerance.

Read variation before location

Confirm the variation estimate is stable before interpreting mean or rate shifts. For multivariate combination charts, evaluate joint variation first.

Investigate signals with process evidence

Link signal numbers to material, setup, maintenance, operators, laboratory conditions, measurement changes, grade transitions, and environmental conditions.

Separate Phase I from Phase II

During baseline development, remove a point only when a documented assignable cause justifies exclusion. After stabilization, save validated limits and use them to monitor future data.

Assess capability only after stability

A process can be stable but incapable, or unstable while all current points happen to meet specifications. Stability and capability answer different questions.

Document the decision

Record chart type, subgroup logic, dates, limits, tests, excluded points and reasons, special-cause findings, corrective action, and owner.

Minitab special-cause tests

TestPatternWhat it can suggest
1One point more than 3σ from the center lineA large isolated special cause.
2Nine points in a row on the same sideA sustained process shift.
3Six points in a row increasing or decreasingA trend or drift.
4Fourteen points alternating up and downSystematic over-adjustment or alternating sources.
5Two of three points more than 2σ from the center line on the same sideA moderate shift.
6Four of five points more than 1σ from the center line on the same sideA small sustained shift.
7Fifteen points in a row within 1σ of the center lineStratification or control limits that are too wide.
8Eight points in a row more than 1σ from the center line on either sideA mixture pattern or limits that are too narrow for the data structure.

Availability varies by chart. Minitab provides Tests 1–8 for most variables charts; R, S, MR, and attribute charts support fewer tests; EWMA and Moving Average support only Test 1; CUSUM, Zone, and multivariate charts use their own signaling logic.

Worked example: choose and run the correct chart

Problem

A rolling mill records one average finishing temperature for each coil. Twenty-five coils are produced in chronological order. The engineer wants to know whether the process mean and short-term coil-to-coil variation are stable.

Step 1: classify the data

  • Response: finishing temperature in °C, so the data are continuous.
  • Sampling: one observation per coil, so subgroup size is 1.
  • Objective: monitor both process location and variation.

Selected chart: I-MR.

Stat > Control Charts > Variables Charts for Individuals > I-MR

Step 2: calculate the underlying statistics

For illustration, suppose the first six temperatures are 798, 801, 799, 803, 802, and 800°C.

Individual-chart center line

x̄ = 798 + 801 + 799 + 803 + 802 + 8006 = 800.5°C

Moving ranges

3, 2, 4, 1, 2°C

For example, |801 − 798| = 3°C.

The average moving range is:

MR̄ = 3 + 2 + 4 + 1 + 25 = 2.4°C

For a moving range of length 2, the short-term standard deviation estimate is:

σ̂ = MR̄d₂ = 2.41.128 = 2.13°C

Approximate I-chart limits are:

UCL = 800.5 + 3(2.13) = 806.9°C    |    LCL = 800.5 − 3(2.13) = 794.1°C

The MR-chart upper limit is approximately:

UCLMR = D₄MR̄ = 3.267(2.4) = 7.84°C

Step 3: run it in Minitab

  1. Place coil sequence in C1 and finishing temperature in C2.
  2. Sort the worksheet from oldest to newest by coil sequence.
  3. Choose Stat > Control Charts > Variables Charts for Individuals > I-MR.
  4. Enter Finishing Temperature as the variable.
  5. Select I-MR Options > Tests. Keep Test 1; add Test 2 if the monitoring plan requires detection of sustained shifts.
  6. Select OK twice.

Step 4: interpret in the correct order

  1. MR chart: investigate any unusually large coil-to-coil jump. If unstable, do not trust the I-chart limits yet.
  2. I chart: investigate points outside limits and nonrandom patterns such as a sustained run above the center line.
  3. Process conclusion: stable does not mean capable. Compare the stable distribution with temperature requirements only after the stability review.
