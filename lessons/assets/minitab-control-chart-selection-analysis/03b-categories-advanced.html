Category 4

Time-Weighted Charts

Continuous data where small sustained shifts matter

These charts use information from previous observations. They can detect small persistent shifts earlier than traditional Shewhart charts when designed and interpreted correctly.

CUSUM

Best for: detecting a small persistent shift from a defined target by accumulating deviations.

Stat > Control Charts > Time-Weighted Charts > CUSUM
Step-by-step Minitab setup
  1. Use individual observations or subgroup means in time order.
  2. Define the target mean and an appropriate standard deviation.
  3. Open CUSUM and enter the variable plus subgroup information if applicable.
  4. Specify the shift size or CUSUM parameters based on the operationally meaningful change.
  5. Interpret upper and lower cumulative paths against decision boundaries.

CUSUM does not use Minitab’s standard tests-for-special-causes menu.

EWMA

Best for: detecting small sustained mean shifts while weighting recent observations more heavily.

Stat > Control Charts > Time-Weighted Charts > EWMA
Step-by-step Minitab setup
  1. Prepare chronological individual values or subgroup means.
  2. Open EWMA and enter the variable plus subgroup information if used.
  3. Enter the EWMA weight λ; smaller values create stronger smoothing.
  4. Use a validated target and standard deviation where available.
  5. Investigate points beyond EWMA limits or sustained movement toward a limit.

Moving Average

Best for: smoothing noise using an equal-weight rolling window.

Stat > Control Charts > Time-Weighted Charts > Moving Average
Step-by-step Minitab setup
  1. Place values in chronological order.
  2. Open Moving Average.
  3. Enter the variable and moving-average length.
  4. Select a window that reflects the process cadence—not one chosen only because it makes the graph smooth.
  5. Interpret the moving averages against their control limits.

Minitab generally recommends EWMA over a simple moving-average chart because EWMA uses all previous observations with decreasing weights.

Category 5

Multivariate Charts

Two or more correlated continuous variables

Use when several correlated measurements jointly describe process condition. A multivariate signal means the combination is unusual; it does not automatically identify the responsible variable.

T²

Best for: monitoring the joint mean vector of correlated continuous measurements.

Stat > Control Charts > Multivariate Charts > T²
Step-by-step Minitab setup
  1. Place each process variable in its own column.
  2. Use rows for the same time point or subgroup.
  3. Open T² and enter the variables plus subgroup IDs if applicable.
  4. Create the chart and investigate out-of-control T² points.
  5. Return to univariate charts, contribution diagnostics, and process records to identify drivers.

Generalized Variance

Best for: monitoring joint dispersion and covariance among correlated variables.

Stat > Control Charts > Multivariate Charts > Generalized Variance
Step-by-step Minitab setup
  1. Enter correlated variables in separate columns with valid subgroups.
  2. Open Generalized Variance.
  3. Specify variables and subgroup identifiers.
  4. Investigate signals indicating changes in multivariate spread or relationships.

T²-Generalized Variance

Best for: jointly monitoring multivariate location and variation.

Stat > Control Charts > Multivariate Charts > T²-Generalized Variance
Step-by-step Minitab setup
  1. Place each correlated variable in a separate column.
  2. Provide subgroup IDs where applicable.
  3. Open the path above and enter the variables.
  4. Use options for stages or historical parameters.
  5. Read Generalized Variance first, then T².
  6. Investigate contributing variables after a signal.

Multivariate EWMA (MEWMA)

Best for: detecting small sustained shifts in the joint means of correlated variables.

Stat > Control Charts > Multivariate Charts > Multivariate EWMA
Step-by-step Minitab setup
  1. Place each correlated variable in its own column.
  2. Open Multivariate EWMA.
  3. Enter variables, subgroup information, and the weighting parameter.
  4. Use a stable baseline covariance structure.
  5. Investigate any signal with variable-level plots and process context.

Category 6

Rare Event Charts

Spacing between infrequent events

Instead of counting events in every period, rare-event charts monitor the number of opportunities or elapsed time between events. On these charts, a lower point often means the adverse event is occurring more frequently.

G

Best for: number of opportunities, units, or whole days between rare events.

Stat > Control Charts > Rare Event Charts > G
Step-by-step Minitab setup
  1. Record event dates or the number of opportunities until/between events.
  2. Open G and select the correct data format.
  3. Enter the event-date or opportunity column.
  4. Consider Tests 1 and 2 and the Benneyan test when appropriate.
  5. Investigate unusually low spacing because it can indicate a worsening event rate.

T

Best for: exact elapsed time between rare events using date-time stamps or continuous durations.

Stat > Control Charts > Rare Event Charts > T
Step-by-step Minitab setup
  1. Record exact event date-times or continuous time intervals.
  2. Open T and choose the matching data format.
  3. Enter the event or elapsed-time column.
  4. Use T Chart Options for tests, distribution settings, or stages where appropriate.
  5. Investigate unusually short times between adverse events.

Use G when only whole-day dates or discrete opportunity counts are available.
