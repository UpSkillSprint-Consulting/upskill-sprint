Before you start

Basic familiarity with averages, variation, and chronological data is helpful. No previous Minitab control-chart experience is required.

Useful mindset: the software menu does not choose the chart for you. The data-generating process, subgroup logic, and monitoring objective determine the method.

Control charts in plain English

A control chart is a time-ordered process graph with statistically calculated limits. It answers: “Is the process behaving like one stable system, or is something unusual changing it?”

What a control chart tells you

  • Whether variation appears consistent over time.
  • Whether an unusual point, shift, trend, cycle, or mixture pattern may require investigation.
  • Whether process changes produced a sustained change.

What it does not tell you

  • Whether the process meets customer specifications.
  • Why a special cause occurred.
  • Whether the measurement system is trustworthy.
  • Whether correlation proves causation.

Key terminology

TermPlain-language meaningPractical interpretation
Common-cause variationRoutine background variation built into the current system.Improve the system; do not chase individual points.
Special-cause variationAn unusual source that is not consistently present.Investigate the specific time, material, setup, equipment, operator, or environment.
Center lineThe expected process level or rate.Usually estimated from baseline data unless a validated historical parameter is entered.
Control limitsExpected boundaries for a stable process.Usually based on approximately ±3 standard deviations, with chart-specific distributions.
Specification limitsEngineering or customer acceptance requirements.They evaluate conformance, not stability. They should not replace control limits.
Rational subgroupObservations collected under nearly identical short-term conditions.Within-subgroup variation represents short-term noise; between-subgroup differences reveal process changes.
DefectiveA unit classified once as pass/fail.Use P, NP, or Laney P′ charts.
DefectAn individual nonconformity; one unit may have several.Use C, U, or Laney U′ charts.
Phase IEstablish and clean a historical baseline.Investigate special causes and estimate defensible limits.
Phase IIMonitor future production against established limits.Use frozen historical limits unless the process is intentionally changed.

Core calculations behind common charts

Subgroup mean

x̄i = Σxijni

Average of the observations in subgroup i.

Range within a subgroup

Ri = xmax,i − xmin,i

Used by R charts and Xbar-R charts for smaller subgroups.

Moving range

MRi = |xi − xi−1|

Measures change between consecutive individual values—or consecutive subgroup means in an I-MR-R/S chart.

Proportion defective

pi = dini

d is the number defective; n is the number inspected.

Defects per unit

ui = cini

c is the number of defects; n is the inspection opportunity.

EWMA statistic

Zt = λxt + (1 − λ)Zt−1

Recent data receive more weight; smaller λ values provide more smoothing.

Golden rule: stabilize the variation chart before interpreting the process-location chart. For Xbar-R, read R before Xbar. For Xbar-S, read S before Xbar. For I-MR, read MR before I. For I-MR-R/S, read R/S, then MR, then I. For T²-Generalized Variance, read Generalized Variance before T².
