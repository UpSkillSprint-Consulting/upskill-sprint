DMAIC in 10 Minutes

DMAIC is the five-step roadmap Lean Six Sigma teams use to fix a problem in a process that already exists. One question per step, answered in order.

The DMAIC roadmap 5 steps, in order

  1. DDefinePin down the problemCharter
  2. MMeasureGet a trusted baselineBaseline
  3. AAnalyzeProve the root causeRoot causes
  4. IImproveFix it, pilot itProven fix
  5. CControlLock in the gainsControl plan

One project, start to finish

A DMAIC project in one chart

A pipe-cutting line re-cuts too many pipes. Follow the bad-cut rate through the five phases. (A made-up example.)

D

Define: agree on the problem

What's the problem, and what does success look like?

Tools

  • Project charter
  • SIPOC
  • Voice of the customer

You finish with

A signed-off project charter

M

Measure: trust the data first

How big is the problem today, and can we trust our measurements?

Tools

  • Gage R&R
  • Data collection plan
  • Process map

You finish with

A baseline you trust: 5.8% bad cuts

A

Analyze: find the root causes

Which causes really drive the problem?

Tools

  • Pareto chart
  • Fishbone and 5 Whys
  • Hypothesis tests

You finish with

Root causes proven with data

I

Improve: fix the causes, then prove it

Which fix removes the root causes, and does it work?

Tools

  • Solution matrix
  • FMEA
  • Pilot run
  • DOE

You finish with

A piloted fix that beats the baseline

C

Control: make the gains stick

How do we stop the process sliding back?

Tools

  • Control chart
  • Control plan
  • Response plan
  • Standard work

You finish with

A control plan handed to the process owner

Tollgates. Each phase ends with a short sponsor review before the next one starts.

Which phase? Sort six real project activities

Pick the phase for each activity. One try each.

Interactive
1. Write a problem statement and agree the project scope with the sponsor.

2. Run a Gage R&R study to check that inspectors measure the same part the same way.

3. Use a Pareto chart and a hypothesis test to check which suspected causes really matter.

4. Pilot a new setup checklist on one shift and compare the results with the baseline.

5. Give the process owner a control chart and a plan for what to do when it signals.

6. Collect four weeks of data to find out how often parts fail today.

Choosing the right tool

Is DMAIC the right tool? Follow the arrows

  1. Does the process already exist?

    NoDesign it new with a design approach such as DMADV.

    ↓ Yes: next question

  2. Do you already know the cause and the fix?

    YesJust do it. No project needed.

    ↓ No: next question

  3. Are customers being hurt right now?

    YesContain it first, then start DMAIC.

    ↓ No: next question

  4. OtherwiseUse DMAIC.

4 ways DMAIC projects go wrong

  • ✕Jumping to a fixSkipping Measure and Analyze treats symptoms.
  • ✕Trusting bad dataCheck the gauge before the baseline.
  • ✕Scoping too bigOne line, one defect, one goal.
  • ✕Skipping ControlNo owner and no plan, and the gains fade.

Exam tip. ASQ's Six Sigma Green Belt and Black Belt bodies of knowledge are organized largely around the DMAIC phases. Expect "which phase does this tool belong to?" questions.
