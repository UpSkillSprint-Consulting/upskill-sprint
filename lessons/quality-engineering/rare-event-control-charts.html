Rare Event Control Charts (G & T)

Rare event control charts ask a different question: how long did we go without an adverse event? Learn to turn raw event logs into actionable evidence, distinguish improvement from deterioration, and reproduce two real Minitab analyses.

G
Count the opportunities

How many good units, transactions or days between events?

T
Measure the elapsed time

How many hours, minutes or days between events?

1. When zero is not enough

Suppose a mill inspects 1,000 pipes per day for critical weld failures. Two failures in ten days give eight zero-count days. A P chart is legitimate, but most points sit at zero and moderate increases in event frequency can be difficult to detect.

Here the CUSUM uses standardized deviation Z and reference value k, EWMA weights the current observation X by lambda, and Hotelling's statistic uses a vector of measurements, baseline means and covariance. Rare-event T is not Hotelling's T².

2. G chart: count the gaps

Use the G chart for independent opportunities with a stable event probability. Examples: critical weld defects, incorrect payments, lost deliveries, surgical infections and serious complaints. If product mix or daily exposure changes materially, stratify or use an exposure-adjusted model.

\[G_i=N_i-N_{i-1}-1\]

Here N is a sequential unit number. If the input is event dates, Minitab uses the actual integer difference in days, without subtracting one. Same-day distinct events generate zero.

The geometric model

\[P(X=x)=p(1-p)^x,\quad F(x)=1-(1-p)^{x+1},\quad x=0,1,2,\ldots\]
\[\widehat p=\frac{n}{n+\sum_{i=1}^n x_i}=\frac{1}{1+\bar x},\quad E(X)=\frac{1-p}{p},\quad \mathrm{Var}(X)=\frac{1-p}{p^2}\]

p is the event probability per opportunity; n is the number of completed intervals; x is the number-between count. The date-based model is a practical approximation when same-day multiple events exist. Its p is not the transaction-level defect probability.

\[Q(q)=\left\lceil\frac{\ln(1-q)}{\ln(1-p)}\right\rceil-1\]
\[LCL=Q(0.00135),\quad CL=Q(0.5),\quad UCL=Q(0.99865)\]

Minitab interpolates between the two adjacent geometric CDF values rather than using integer quantiles directly, then clips the lower limit at zero. For adjacent integer counts a and b=a+1 with F(a) ≤ q ≤ F(b), the interpolated value is:

\[Q_{\mathrm{interp}}(q)=a+\frac{q-F(a)}{F(b)-F(a)}\]

At p=0.005, the mean is 199 good pipes; the interpolated median is about 137.28 and the UCL about 1,317.22. The LCL is zero. A gap of 1,550 may indicate improvement; two successive zero gaps indicate a cluster.

Benneyan test: catch repeated zeros

When the LCL is zero, a nonnegative count cannot fall below it. The Benneyan test counts consecutive points equal to the LCL; for the zero-LCL case the threshold is:

\[r=\left\lceil\frac{\ln[\Phi(-K)]}{\ln p}\right\rceil\]

K is the Test 1 normal-equivalent threshold (default 3); Phi is the standard normal CDF. At p=0.005, r=2; at p=0.08, r=3. Three zero gaps mean four distinct events on the same date, or four consecutive defective units in a unit-based chart.

3. T chart: measure the time

Use the T chart when exact timestamps or actual operating durations are available. Examples include equipment trips, server outages, compressor failures and incidents per operating hour.

\[T_i=t_i-t_{i-1}\]

t is the event timestamp. Use a consistent time unit and actual exposure when equipment is idle.

Exponential

Constant hazard. Scale equals mean time between events.

\[f(t)=\lambda e^{-\lambda t},\quad F(t)=1-e^{-\lambda t}\]
\[\lambda=1/\theta,\quad\widehat\theta=\bar t\]

Weibull

Flexible hazard. Shape determines whether hazard rises or falls.

\[F(t)=1-e^{-(t/\eta)^\beta}\]
\[f(t)=\frac{\beta}{\eta}(t/\eta)^{\beta-1}e^{-(t/\eta)^\beta}\]
\[E(T)=\eta\Gamma(1+1/\beta),\qquad h(t)=\frac{\beta}{\eta}(t/\eta)^{\beta-1}\]

theta is exponential scale, lambda is rate, beta is Weibull shape, eta is Weibull scale, and Gamma is the gamma function. The exponential estimator is the mean of complete positive intervals; Minitab uses a different fitting procedure if zero durations are present.

\[Q_{\mathrm{exp}}(q)=-\theta\ln(1-q),\qquad Q_{\mathrm{Wei}}(q)=\eta[-\ln(1-q)]^{1/\beta}\]
\[LCL=Q(0.00135),\quad CL=Q(0.5),\quad UCL=Q(0.99865)\]

6. Phase I vs. Phase II

Phase I · establish

Use a reference period, inspect signals and investigate special causes before freezing limits.

Phase II · monitor

Apply the frozen parameters to the subsequent observations. Do not let a deteriorating process redefine its own benchmark.

  1. Subset the first 26 event records (25 completed intervals), e.g. Data → Subset Worksheet.
  2. Recreate each chart, leaving historical parameters blank. Evaluate baseline stability and model suitability.
  3. Record the parameters, then apply them to the complete data. Do not automatically use Period as a stage variable; default stage limits can be recalculated independently.
  4. Compare an exponential and Weibull T chart using a distribution identification plot for complete positive intervals. Evaluate fit and engineering plausibility.

Expected reference estimates: geometric number-between model p = 1/(1+12.12) ≈ 0.07622; exponential scale ≈ 5.76025 days. Your signal patterns may change with the limits.

7. Why tests matter, and common mistakes

Test 1

One extreme interval beyond a probability limit. The lower tail is often close to zero.

Test 2

Nine successive points on one side of the median detect sustained change.

Benneyan

Repeated intervals equal to the G chart lower limit; useful when zero gaps cluster.

Specialized CUSUM / EWMA

Distribution-aware rare-event versions can detect smaller shifts. Ordinary normal CUSUM/EWMA limits should not be applied blindly to skewed gaps.
CheckWhy
Chronological, complete reportingMissed events inflate gaps
Independent intervals and consistent definitionClustering changes signal probabilities
Comparable exposure and event riskCalendar gaps may mislead during shutdown or volume changes
Suitable distributionMisfit gives misleading limits
Enough stable reference dataFew events produce uncertain parameters
Ongoing intervalRight-censored until another event occurs
Control vs capabilityStable does not necessarily mean acceptable

A high point may signal improvement, but investigate both directions. A lower control limit is not a target or a specification.

Excel Use Cases

Put chronologically sorted dates in B2:B39, leave C2 blank, and fill =DAYS(B3,B2) down for the G log. For timestamps use =B3-B2 and format C as Number, then multiply by 1,440 for minutes. Estimate the baseline using C3:C27 (25 intervals). For G use =1/(1+AVERAGE(C3:C27)); for T use =AVERAGE(C3:C27).

For historical exponential scale in E2, use =-E2*LN(0.99865), =E2*LN(2), =-E2*LN(0.00135). For Weibull shape in E3 raise each negative logarithm to 1/E3. In EXPON.DIST use the rate, not the scale; in WEIBULL.DIST use shape and scale.

Minitab Navigation

Stat → Control Charts → Rare Event Charts → G for dates/counts; Stat → Control Charts → Rare Event Charts → T for timestamps/durations. See the practice above. For direct count data, select Number of opportunities between events or Number of opportunities until an event as appropriate; Minitab converts until counts to between counts.

Exam Tips

Focus on chart selection, distribution assumptions, common versus special causes, false alarms, and interpreting data against a stable baseline. G/T charts are useful applied SPC methods; do not assume they are named explicitly in the ASQ CQE or CSSBB exam outlines. Consult the applicable current body of knowledge.
