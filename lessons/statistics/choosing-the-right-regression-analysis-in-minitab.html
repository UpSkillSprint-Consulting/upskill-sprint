Choosing the Right Regression Analysis in Minitab

Understand how each regression procedure works, what it searches, and when to choose it.

By the end, you should be able to

  • Choose between Fitted Line Plot, Fit Regression Model, Best Subsets, and Nonlinear Regression.
  • Explain Stepwise, Forward, Backward, Information Criteria, and Forward Selection with Validation.
  • Handle interactions, hierarchy, polynomial terms, diagnostics, and validation correctly.

Regression foundations

Regression relates a response Y to one or more predictors X. Simple regression uses one predictor; multiple regression uses several.

ŷ = b₀ + b₁X₁ + b₂X₂ + ··· + bₖXₖ
Linear does not mean visually straight. A polynomial such as Y = b₀ + b₁X + b₂X² is curved but still linear in its coefficients.

Fitted Line Plot

Stat → Regression → Fitted Line Plot

Use it for one continuous X and one continuous Y. It combines a scatterplot, fitted equation, R², significance results, and optional residual plots. It is ideal for exploring one predictor at a time, but it cannot adjust for confounding by other predictors.

Fit Regression Model

Stat → Regression → Regression → Fit Regression Model

This is Minitab’s main linear-model procedure. It supports multiple continuous predictors, categorical factors, interactions, and polynomial terms. Selecting None in the Stepwise dialog means Minitab fits exactly the model you specify.

How the automatic selection methods work

Forward Selection

Start with the intercept. With candidates A, B, C, D, E, and F, Minitab tests each possible first addition. Suppose A has the smallest qualifying p-value; A enters. It then tests A+B, A+C, A+D, A+E, and A+F. If B wins, the path becomes A → A+B. Terms enter one at a time and ordinarily do not leave.

Backward Elimination

Start with A+B+C+D+E+F. Remove the included term with the largest p-value above alpha-to-remove, refit, and repeat. The full starting model must be estimable.

Stepwise

Stepwise combines forward entry and backward checking. A possible path is A → A+B → A+B+C → A+C when B becomes non-significant after C enters. Terms may enter, leave, and sometimes re-enter.

Forward Information Criteria

Builds forward using AIC/AICc-style fit-versus-complexity criteria rather than only individual p-values. A retained term can have p > 0.05 if it improves the overall information criterion.

Forward Selection with Validation

Critical correction: validation does not normally decide which variable enters next. The forward stepwise significance rule builds one sequence of models; validation identifies the preferred model size or step along that sequence.
  1. Start with the intercept.
  2. Test A, B, C, D, E, and F using the forward entry rule. Suppose A enters.
  3. Test A+B, A+C, A+D, A+E, and A+F. Suppose B enters.
  4. Continue to form a nested path such as A → A+B → A+B+C → A+B+C+D.
  5. Calculate validation error for each completed model.
  6. Select the step with the best validation performance, even if larger models were constructed later.

A12.9
A+B8.7

The selected model is A+B+C. This is not brute force and can miss combinations that are not on the forward path.

Best Subsets Regression

Stat → Regression → Regression → Best Subsets

Best Subsets compares alternative predictor combinations. With six predictors it can examine 2⁶−1 = 63 non-empty subsets. Compare R², adjusted R², predicted R², S, and Mallows’ Cp. Do not choose from ordinary R² alone because R² cannot decrease when terms are added.

Interactions are not created automatically. Best Subsets only searches the worksheet columns supplied. To evaluate A×B, create a column using Calc → Calculator and enter A*B.

Best Subsets treats A_B as an ordinary numeric predictor and may select it without A and B. Apply hierarchy manually: when A×B is retained, ordinarily retain A and B.

Better workflow when you have many interactions

Use Fit Regression Model instead of manually building many interaction columns.

  1. Enter Y as the response.
  2. Enter A, B, and C as continuous predictors; enter categorical variables as factors.
  3. Click Model.
  4. Select A, B, and C.
  5. Choose interactions through order 2 and click Add.
  6. Open Stepwise and select the desired method.
  7. Require hierarchy so an interaction keeps its parent main effects.
For A, B, and C, Minitab can generate A, B, C, A×B, A×C, and B×C automatically. This is usually safer for structured engineering models and categorical-factor interactions.

Nonlinear Regression

Stat → Regression → Nonlinear Regression

Use it when the scientific equation is nonlinear in its unknown parameters, such as Y = a·exp(bX), Y = aX/(b+X), or Y = a(1−exp(−bX)). You supply an expectation function and starting parameter values; Minitab iteratively adjusts the parameters.

Curvature alone does not require Nonlinear Regression. Use ordinary regression for polynomial terms such as X² and X³.

Diagnostics and model statistics

  • R²: training-data variation explained; favors larger models.
  • Adjusted R²: penalizes unnecessary terms.
  • Predicted R²: estimates prediction on new observations.
  • S: typical residual size in response units.
  • Mallows’ Cp: useful for comparing Best Subsets candidates.
  • VIF: diagnoses multicollinearity.
  • Residual plots: check linearity, constant variance, normality where relevant, independence, and unusual observations.

Recommended workflow

  1. Define the response type and modeling purpose.
  2. Plot the data and use engineering knowledge to specify plausible terms.
  3. Fit a defensible full model and check VIF and residuals.
  4. Use selection methods to generate candidates, not as proof.
  5. Respect hierarchy for interactions and polynomials.
  6. Validate using predicted R², held-out data, or cross-validation.
  7. Select the simplest stable model that is physically credible and sufficiently predictive.
