Choosing a Transformation to Linearize Data

Your scatter plot curves, and a straight-line regression will not fit it honestly. This lesson shows you how to pick the transformation that makes the relationship linear: which variable to change, which power to use, how to let the data choose, how to prove it worked, and when no transformation will help.

  • Intermediate
  • 75 min
  • 6 interactive tools
  • Excel · Minitab · Python

By the end you can

  • Read the shape of a curve and pick a move on the ladder of powers.
  • Decide whether to transform x, y, or both, from the residual spread.
  • Estimate the power with Box–Cox for y and Box–Tidwell for x.
  • Prove the fix with residual checks and compare models fairly.
  • Back-transform predictions without bias and recognise when to stop transforming.

Part 1

Why straighten a curved scatter plot?

Ordinary least-squares regression assumes four things about the model \( y = \beta_0 + \beta_1 x + \varepsilon \): the mean of \(y\) is a straight-line function of \(x\), the errors \(\varepsilon\) have constant variance, they are independent, and for intervals and tests they are roughly normal. A curved scatter plot breaks the first assumption. A plot that fans out breaks the second. A transformation re-expresses one or both variables so that both assumptions hold on the new scale.

Straightening pays off in three ways. The model fits the data, so residuals carry no leftover pattern. The slope becomes a single, interpretable number such as a growth rate or an exponent. And confidence and prediction intervals have the right width everywhere, not too narrow at one end and too wide at the other.

Two different problems, one family of fixes. Curvature is a problem with the mean. Uneven spread is a problem with the variance. Transforming y changes both. Transforming x changes only the mean. Keeping that distinction in mind is most of the skill.

You do not always need to linearize. If you only need predictions and have plenty of data, a nonlinear model or a flexible method may serve you better. If physics hands you a nonlinear law with parameters you care about, fit that law directly with nonlinear regression. Part 13 covers these exits.

Part 2

The ladder of powers

John Tukey arranged the useful re-expressions in order of strength, as powers \(x^{p}\). Moving down the ladder (smaller \(p\)) pulls in large values and spreads out small ones. Moving up (larger \(p\)) does the opposite. The further you move from \(p = 1\), the stronger the bend you remove.

Why the log sits at power 0

The raw power \(x^{0}\) is just 1, which is useless. The Box–Cox form fixes this by scaling each power so the ladder is continuous:

\[ x^{(\lambda)} = \begin{cases} \dfrac{x^{\lambda} - 1}{\lambda}, & \lambda \ne 0 \\[6pt] \ln x, & \lambda = 0 \end{cases} \qquad\text{because}\qquad \lim_{\lambda \to 0} \frac{x^{\lambda} - 1}{\lambda} = \ln x . \]

where \(x > 0\) and \(\lambda\) is the power. The limit follows from \(x^{\lambda} = e^{\lambda \ln x} \approx 1 + \lambda \ln x\) for small \(\lambda\). Dividing by \(\lambda\) also keeps the order of the points for negative powers. That is why the lab and the table write \(-1/x\) rather than \(1/x\): the minus sign stops the plot from flipping left to right, so the direction of the trend stays easy to read.

Range matters. Power transformations only bend data that span a wide ratio. If the largest value is less than about twice the smallest, every rung looks almost the same. Look for an offset to subtract first, or use a polynomial term. The Recovery time dataset in the lab shows this.

Part 3

Read the bend with Tukey's bulge rule

Look at which corner of the plot the curve bulges toward. Then move each variable in the direction of the bulge: if it bulges up, move y up the ladder; down, move y down. If it bulges right, move x up; left, move x down. You can move either variable, or both a little. Pick a quadrant to see what it means.

Rises fast, then flattens

The rule tells you the direction, not the distance. Start one rung away, check the plot, and keep going until the bend disappears or reverses. If it reverses, you went too far; step back half a rung. The lab below lets you do exactly that, and Parts 7 and 8 replace trial and error with estimates.

How the two checks work

The curvature check is a partial F-test. It refits the transformed data with squared and cubed terms added and asks whether they explain significantly more than the straight line:

\[ F = \frac{(\text{SSE}_{1} - \text{SSE}_{3})/2}{\text{SSE}_{3}/(n-4)} \]

where \(\text{SSE}_{1}\) is the error sum of squares of the straight line, \(\text{SSE}_{3}\) that of the cubic, and \(n\) the number of points. A p-value below 0.05 means a curve remains. The cubic term matters: a symmetric S-curve has no quadratic signal, so a quadratic-only test would miss it.

The spread check correlates the absolute residuals \(|e_i|\) with the fitted values \(\hat{y}_i\) and tests that correlation with \(t = r\sqrt{n-2}/\sqrt{1-r^{2}}\). A p-value below 0.05 means the spread trends with the level: a funnel. Both checks are screening tools. With large samples they flag tiny departures, and with small ones they miss real ones, so always look at the residual plot too.

Watch the two \(R^{2}\) values. The transformed-scale \(R^{2}\) describes the line you fitted, but it is measured in different units for every choice of y. The original-scale \(R^{2}\) back-transforms the predictions and scores them against the raw y, so it is comparable across choices.

Part 5

Match the curve to a known model

Before you reach for the ladder, ask whether the process already has a law. If it does, the law tells you the exact transformation and gives the slope a physical meaning. Many engineering relationships are one of a handful of forms.

Exponential or power? They look alike on raw axes. Plot both: if \(\ln y\) vs \(x\) is straight, it is exponential; if \(\ln y\) vs \(\ln x\) is straight, it is a power law. An exponential curves upward on log–log paper, and a power law curves downward on semi-log paper.

Part 6

Which axis to transform: curvature or spread?

The bulge rule says you may move x or y. The residual spread decides which. Look at the residuals from a straight-line fit on raw data:

  • Spread is even, only the trend curves. Transform x. It straightens the mean and leaves the well-behaved errors alone.
  • Spread grows with the level (a funnel). Transform y. The error is multiplicative, and the right y transform usually removes the curve as well.
  • Both problems, and fixing y over-corrects the curve. Fix the spread with y first, then straighten what is left with x.

Choosing the y transform from the mean–variance relationship

The delta method gives the variance of a transformed variable \(g(Y)\) with mean \(\mu\):

\[ \operatorname{Var}\!\left[g(Y)\right] \approx \left[g'(\mu)\right]^{2} \operatorname{Var}(Y). \]

If the standard deviation grows as a power of the mean, \(\sigma_Y \propto \mu^{k}\), then choosing \(g(y) = y^{1-k}\) gives \(g'(\mu) \propto \mu^{-k}\), and the variance of \(g(Y)\) becomes constant. So the variance-stabilizing power is \(\lambda = 1 - k\).

\[ \begin{aligned} \sigma_Y \propto \mu^{k} \quad&\Longrightarrow\quad \lambda = 1 - k \\ k = 0.5\ \text{(counts)} \quad&\Longrightarrow\quad \lambda = 0.5,\ \sqrt{y} \\ k = 1\ \text{(constant CV)} \quad&\Longrightarrow\quad \lambda = 0,\ \ln y \\ k = 2 \quad&\Longrightarrow\quad \lambda = -1,\ 1/y \end{aligned} \]

where \(k\) is estimated as the slope of \(\ln(\text{SD})\) against \(\ln(\text{mean})\) across groups or bins of x.

Transforming y moves the errors with it. If y has constant spread and you take its log, you create a reverse funnel: small y values spread out and large ones get squeezed. Load Yield strength vs grain size in the lab and set y to \(\ln y\) to see that the spread check gets worse, not better.

Part 7

Let the data choose y: the Box–Cox method

Box and Cox (1964) proposed estimating the power for y by maximum likelihood. To compare SSE across powers, the transformed response must be on a common scale, so it is divided by a power of the geometric mean \(\dot{y}\):

\[ z^{(\lambda)} = \begin{cases} \dfrac{y^{\lambda} - 1}{\lambda\,\dot{y}^{\,\lambda - 1}}, & \lambda \ne 0 \\[6pt] \dot{y}\,\ln y, & \lambda = 0 \end{cases} \qquad \dot{y} = \exp\!\left(\frac{1}{n}\sum_{i=1}^{n} \ln y_i\right) \]

where \(y_i > 0\). For each \(\lambda\), regress \(z^{(\lambda)}\) on the predictors and record the error sum of squares \(\text{SSE}(\lambda)\). The profile log-likelihood is

\[ \ell(\lambda) = -\frac{n}{2}\ln\!\left(\frac{\text{SSE}(\lambda)}{n}\right), \qquad \text{95\% CI: } \left\{\lambda : \ell(\lambda) \ge \ell(\hat{\lambda}) - \tfrac{1}{2}\chi^{2}_{1,\,0.95}\right\} \]

where \(\hat{\lambda}\) maximises \(\ell\) and \(\tfrac{1}{2}\chi^{2}_{1,\,0.95} = 1.92\). In practice you then round to the simplest rung inside the interval (1, 0.5, 0, −0.5, −1). A rounded power is easier to explain, and the fit is almost as good.

The Box–Cox menu trap. Minitab's Stat > Control Charts > Box-Cox Transformation, Python's scipy.stats.boxcox and most "normalize this column" tools look at y alone. They choose \(\lambda\) to make the distribution of y look normal. That is the right question for a capability study, but the wrong one for regression. In regression the residuals must be normal and even, and y itself can have any shape because x moves it around. Use the Box–Cox option inside the regression dialog, which profiles the SSE of the model as above.

Box–Cox has limits. It needs every y to be positive. It optimises normality and constant variance together with linearity, so when those goals conflict the estimate is a compromise. A single outlier can drag \(\hat{\lambda}\) a long way, so check the profile after removing any point with a large residual.

Part 8

Let the data choose x: the Box–Tidwell method

When the spread is already even, you want to transform x, not y. Box and Tidwell (1962) estimate the power \(\alpha\) in \(E(y) = \beta_0 + \beta_1 x^{\alpha}\) with a short iteration based on a Taylor expansion around the current guess \(\alpha_0\):

\[ \begin{aligned} x^{\alpha} &\approx x^{\alpha_0} + (\alpha - \alpha_0)\,x^{\alpha_0}\ln x \\ &= z + \frac{\alpha - \alpha_0}{\alpha_0}\, z \ln z, \qquad z = x^{\alpha_0} \end{aligned} \]

So the iteration is:

  1. Fit \(y = \beta_0 + \beta_1 z\) and keep \(\hat{\beta}_1\).
  2. Fit \(y = \beta_0 + \beta_1 z + \gamma\, z \ln z\) and keep \(\hat{\gamma}\).
  3. Update \(\alpha_1 = \alpha_0\left(1 + \hat{\gamma}/\hat{\beta}_1\right)\) and repeat until it settles.

where \(z\) is x raised to the current power and \(\gamma\) is the coefficient on the correction term. Starting at \(\alpha_0 = 1\), one step is often close enough. A t-test on \(\hat{\gamma}\) in the first step is also a test of whether any power transformation of x is needed.

Minitab has no Box–Tidwell command, but you can run the one-step version by hand: create \(x\ln x\) with Calc > Calculator, add it to the regression, and compute \(1 + \hat{\gamma}/\hat{\beta}_1\). R users have car::boxTidwell(). Like Box–Cox, it needs positive x, and it can diverge when the curve is not a power of x at all. Divergence is information: it tells you to look for a different model, an offset, or a curve that changes direction.

Part 9

Zeros, negatives, proportions and offsets

Zeros

\(\ln 0\) and \(1/0\) do not exist. The usual patch is \(\ln(y + c)\), but the answer depends on \(c\). Adding 1 to counts in the hundreds changes almost nothing; adding 1 to counts near 0 changes the shape completely. If you must shift, choose \(c\) for a reason (half the detection limit, or the smallest non-zero value divided by two), report it, and check that the conclusions survive a different \(c\). Often the better answer is \(\sqrt{y}\), which handles zeros, or a Poisson or Tweedie model with a log link, which models \(\ln E(y)\) without ever logging a zero.

Negative values

The power ladder needs positive data. For variables that cross zero (deviations, residuals, temperature in °C), use the Yeo–Johnson transformation, which applies Box–Cox to \(y + 1\) for \(y \ge 0\) and a mirrored version for \(y < 0\):

\[ \psi(\lambda, y) = \begin{cases} \dfrac{(y + 1)^{\lambda} - 1}{\lambda}, & y \ge 0,\ \lambda \ne 0 \\[6pt] \ln(y + 1), & y \ge 0,\ \lambda = 0 \\[6pt] -\dfrac{(1 - y)^{2 - \lambda} - 1}{2 - \lambda}, & y < 0,\ \lambda \ne 2 \\[6pt] -\ln(1 - y), & y < 0,\ \lambda = 2 \end{cases} \]

Better still, ask whether the variable has a natural zero. Temperature converted to kelvin is positive, and Arrhenius needs kelvin anyway.

Proportions and percentages

A proportion is trapped between 0 and 1, so its relationship with x flattens at both ends into an S-curve. The logit \(\ln[p/(1-p)]\) stretches both ends to infinity and usually straightens it. Exact 0% and 100% readings are undefined on the logit scale; with counts behind them, use logistic regression on the counts instead of transforming percentages.

Offsets and start values

Many curves are power laws in \(x - x_0\), not in \(x\): a threshold stress, an ambient temperature, a minimum detectable level. When the data span a narrow ratio, no rung bends them, but subtracting the right \(x_0\) restores a wide ratio and the ladder works again. Load Recovery time vs set-point in the lab, try \(-1/x\) with no offset, then set the offset to 95.

Part 10

Check that the transformation worked

A transformation is a hypothesis about the data. Test it the same way you test any regression model:

  1. Residuals vs fitted. A horizontal band with no curve and no funnel. This is the single most important plot.
  2. Residuals vs each predictor. Catches curvature in one x that the fitted-value plot hides in a multiple regression.
  3. Normal probability plot of residuals. Roughly straight. Heavy tails after transforming may mean outliers rather than the wrong power.
  4. Residuals in time order. Transformations do nothing for autocorrelation or drift.
  5. Lack-of-fit test. With replicate x values, Minitab's pure-error lack-of-fit test checks linearity formally.

Comparing models fairly

\(R^{2}\) measures the share of variance explained in the response you fitted. If one model predicts \(y\) and another predicts \(\ln y\), their \(R^{2}\) values describe different quantities and cannot be ranked. Three fair comparisons:

  • Back-transform each model's predictions to the original scale and compute \(R^{2}_{\text{orig}} = 1 - \sum(y_i - \tilde{y}_i)^{2} / \sum(y_i - \bar{y})^{2}\), where \(\tilde{y}_i\) is the back-transformed prediction. The lab reports this.
  • Compare the Box–Cox log-likelihood \(\ell(\lambda)\) at each candidate power. The geometric-mean scaling makes them comparable.
  • Compare out-of-sample prediction error on the original scale with cross-validation.

Comparing models with different x transforms but the same y is simpler: the \(R^{2}\) values and \(S\) are directly comparable.

Step 1: the raw fit looks good and is wrong. A straight line on raw y gives \(R^{2} = 0.943\). The residuals run plus, minus, minus, minus, minus, plus: a U-shape. The curve bulges down and right, and the jumps between points grow with y, which suggests a multiplicative process. Move y down.

Step 2: fit \(\ln y\) on x.

\[ \begin{aligned} \widehat{\ln y} &= -0.5430 + 0.3415\,x \\ R^{2} &= 0.9998 \end{aligned} \]

The residuals on the log scale are all within \(\pm 0.015\) with no pattern. Strictly, \(0.9998\) cannot be compared with \(0.943\) because the responses differ; the evidence is the residual pattern.

Step 3: interpret the slope. Each extra thousand tonnes multiplies the defect rate by \(e^{0.3415}\):

\[ \begin{aligned} e^{0.3415} &= 1.407 \;\Rightarrow\; +40.7\% \text{ per kt} \\ \text{Doubling distance} &= \frac{\ln 2}{0.3415} = 2.03\ \text{kt} \end{aligned} \]

Step 4: back-transform a prediction. At 7 kt the model gives \(\widehat{\ln y} = -0.5430 + 0.3415 \times 7 = 1.8478\), so the predicted median rate is \(e^{1.8478} = 6.35\) defects per 100 pipes. The smearing correction here is \(\tfrac{1}{n}\sum e^{e_i} = 1.00003\) because the residuals are tiny, so the mean and median agree. With noisier data they would not; Part 12 shows how far apart they can drift.

Step 5: act. The rate doubles about every 2 kt. Seven kilotonnes is outside the observed range, so treat the 7 kt figure as a warning for planning the next roll change, not a forecast to bank on.

Part 12

Back-transforming predictions and coefficients

Fitting on a transformed scale is the easy half. Your audience wants answers in MPa, percent, and defects per 100 pipes.

Reading the coefficients

Retransformation bias

Transforming back with the inverse function gives the right answer for quantiles, because monotone functions preserve order. So \(e^{\widehat{\ln y}}\) is a good estimate of the median of y. It is not the mean. If the log-scale errors are normal with variance \(\sigma^{2}\), the mean on the original scale is larger:

\[ E(y \mid x) = \exp\!\left(\mu_x + \tfrac{1}{2}\sigma^{2}\right) \]

where \(\mu_x\) is the log-scale prediction. Duan's smearing estimator makes no normality assumption. It multiplies the naive back-transform by the average of the exponentiated residuals \(e_i\):

\[ \hat{E}(y \mid x) = e^{\hat{\mu}_x} \cdot \frac{1}{n}\sum_{i=1}^{n} e^{e_i} \]

Use the median when you are describing a typical part. Use the mean when you are summing across parts, such as total scrap cost or total defects per shift. Interval endpoints back-transform directly: exponentiate the lower and upper limits of a prediction interval on the log scale and you get a valid, asymmetric interval on the original scale.

Part 13

What does not work

These are the mistakes that show up most in reports and exam questions. Open each one for the reason and the fix.

Picking the transformation with the highest \(R^{2}\)

Each choice of y changes what \(R^{2}\) measures, and logs often inflate it by compressing the large, noisy values. Choose from residual plots, theory, and the original-scale or Box–Cox comparison in Part 10.

Laddering a curve that changes direction

Every rung is monotone, so it can bend a curve but never unbend a U, a peak, or an S. Add a squared term, fit a spline, or use a model with the right shape (logistic, hyperbolic tangent).

Running Box–Cox on y alone

Control-chart Box–Cox and column-normalizing tools ignore x. A response that depends strongly on x can look skewed while its residuals are perfect. Profile the regression SSE instead.

Logging y when only the trend is curved

If the residual spread is even, logging y creates a funnel in the other direction. Straighten with x and leave the good errors alone.

Adding 1 to dodge the zeros

\(\ln(y+1)\) is a different transformation for every scale of y. Results can flip with the choice of constant. Use \(\sqrt{y}\), a stated and justified constant, or a model with a log link.

Expecting a log to bend a narrow range

When \(x_{\max}/x_{\min}\) is close to 1, \(\ln x\) is almost linear in x. The curvature is coming from somewhere else, often an offset. Subtract it or use a polynomial.

Reporting \(e^{\hat{\mu}}\) as the average

It estimates the median. Totals and costs built from it will be low. Apply the smearing or lognormal correction.

Transforming to hide an outlier

A log can pull a wild point into line, but if the point is a recording error or a different process, it still is. Investigate first, then decide whether it belongs in the model.

Extrapolating on the transformed scale

A line on log axes becomes an exponential on raw axes, so small slope errors grow fast outside the data. Keep predictions inside the observed range, or say clearly that they are extrapolations.

Transforming to fix drift or autocorrelation

Transformations change scale, not time structure. Residuals that wander in time order need time terms, blocking, or time-series methods.

Transforming one group but not another

When you compare groups, or include several predictors, the same transformation must apply to every observation of a variable. Mixing scales makes the coefficients meaningless.

Forgetting the spec limits in capability work

If you transform data to compute \(C_{pk}\), transform the specification limits with the same power. Minitab does this automatically; a hand calculation often does not.

Part 14

When to stop transforming

Transformations are a tool, not a goal. Stop and switch methods when any of these is true.

      Excel Use Cases

      Assume x in A2:A41 and y in B2:B41.

      Power law (log–log). In C2 enter =LN(A2), in D2 enter =LN(B2), and fill down. The exponent is =SLOPE(D2:D41,C2:C41) and the coefficient is =EXP(INTERCEPT(D2:D41,C2:C41)).

      Exponential in one step. =INDEX(LOGEST(B2:B41,A2:A41),1) returns \(m\); the growth per unit of x is =INDEX(LOGEST(B2:B41,A2:A41),1)-1. =LN(INDEX(LOGEST(B2:B41,A2:A41),1)) equals the slope of \(\ln y\) on x.

      Box–Cox profile. Put a trial \(\lambda\) in H1. In E2 enter =IF($H$1=0,GEOMEAN($B$2:$B$41)*LN(B2),(B2^$H$1-1)/($H$1*GEOMEAN($B$2:$B$41)^($H$1-1))) and fill down. Then SSE is =DEVSQ(E2:E41)*(1-RSQ(E2:E41,A2:A41)). Use Data > What-If Analysis > Data Table over \(\lambda\) from −2 to 2, pick the smallest SSE, and keep every \(\lambda\) whose SSE is below =MIN(SSE range)*EXP(CHISQ.INV(0.95,1)/40) as the 95% interval.

      Fair \(R^{2}\) on the original scale. After fitting \(\ln y\), put =EXP(TREND($D$2:$D$41,$A$2:$A$41,A2)) in F2 and fill down. Then =1-SUMXMY2(B2:B41,F2:F41)/DEVSQ(B2:B41).

      Smearing correction. With log-scale residuals in G2:G41, the factor is =AVERAGE(EXP(G2:G41)) in Excel 365 (enter as an array formula in older versions). Multiply each back-transformed prediction by it.

      Chart trendline caution. Excel's Exponential and Power trendlines fit on the log scale, and the \(R^{2}\) they display is the log-scale value. Do not set it beside a Linear trendline's \(R^{2}\) and pick the bigger number.

      Exam Tips

      • Memorise the Box–Cox map: \(\lambda = 2\) square, 1 none, 0.5 square root, 0 natural log, −0.5 reciprocal square root, −1 reciprocal. Box–Cox needs strictly positive data.
      • ASQ CSSBB and CQE questions often pair data types with transforms: counts → square root, proportions → arcsine square root, multiplicative or right-skewed data → log.
      • For capability on transformed data, both the data and the specification limits are transformed with the same \(\lambda\). Johnson transformation is the alternative when Box–Cox fails.
      • On a log–log plot the slope is an exponent; on a semi-log plot (\(\log y\)) the slope is a growth rate. Expect a question that asks which plot makes an exponential straight.
      • Higher \(R^{2}\) after transforming y is not evidence that the model is better. Answer choices that rely on it are usually the distractor.
      • In practice, record the transformation, the reason, and the back-transform method in the analysis report so the next engineer can reproduce it.

      Python and R equivalents

      The same workflow in code: profile Box–Cox on the regression, run one Box–Tidwell step, and back-transform with smearing.

      import numpy as np
import statsmodels.api as sm
from scipy import stats

def boxcox_profile(x, y, lambdas=np.arange(-2, 3.01, 0.01)):
    """Regression-aware Box-Cox: profile SSE of z(lambda) on x."""
    gm = np.exp(np.mean(np.log(y)))
    X = sm.add_constant(x)
    ll = []
    for lam in lambdas:
        z = gm * np.log(y) if abs(lam) < 1e-9 else (y**lam - 1) / (lam * gm**(lam - 1))
        sse = sm.OLS(z, X).fit().ssr
        ll.append(-len(y) / 2 * np.log(sse / len(y)))
    ll = np.array(ll)
    best = lambdas[ll.argmax()]
    ci = lambdas[ll >= ll.max() - stats.chi2.ppf(0.95, 1) / 2]
    return best, (ci.min(), ci.max())

def box_tidwell_step(x, y, alpha=1.0):
    """One Box-Tidwell update for the power on x (x > 0)."""
    z = x**alpha
    b1 = sm.OLS(y, sm.add_constant(z)).fit().params[1]
    gamma = sm.OLS(y, sm.add_constant(np.column_stack([z, z * np.log(z)]))).fit().params[2]
    return alpha * (1 + gamma / b1)

# Fit ln(y) on x, then back-transform with Duan's smearing estimator
fit = sm.OLS(np.log(y), sm.add_constant(x)).fit()
smear = np.mean(np.exp(fit.resid))
mean_pred = np.exp(fit.fittedvalues) * smear      # mean of y
median_pred = np.exp(fit.fittedvalues)            # median of y

# Counts: model the mean directly instead of transforming
poisson = sm.GLM(counts, sm.add_constant(length), family=sm.families.Poisson()).fit()
      library(MASS)   # boxcox()

fit <- lm(y ~ x)
