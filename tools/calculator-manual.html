1 · Quick Start

The tool has eight workspaces along the top:

  • Scientific Calculator — a full natural-display calculator that operates like a Casio fx-300ES PLUS 2: you type into stacked fractions, radicals, and exponents, with a SHIFT/ALPHA keypad, memory registers, and a history tape.
  • Distributions — probability calculator for 16 distributions with live shaded-region plots, critical values, and reliability metrics.
  • Hypothesis Tests — ten test presets that compute the statistic, p-value, and decision, and draw the rejection region.
  • Data & Quality — raw-data summaries, regression, capability, I-MR, ANOVA and chi-square.
  • Graphing — function, parametric, polar and sequence plots, tables and numerical calculus.
  • Lists & Matrices — advanced expressions, complex numbers, units and a supported-function catalog.
  • Finance — TVM and amortization, with NPV/IRR in the math workspace.
  • Programs — bounded calculation programs using the documented command subset.
30-second example — evaluate √(59 ÷ 8) + 44
Press √□ → type 59 → press □⁄□ (59 jumps onto the fraction bar) → type 8 → press ▶ twice to climb out → + 44 → =
Result: 46.71634… — the live "ghost" line shows the answer even before you press =

3 · Typing Equations — the Natural Display Editor

The equation area is a structural editor: the math on screen is the input itself, not a preview. You can drive it entirely from the keypad, entirely from your keyboard, or mix both.

Creating structures

You pressWhat happens
/ (keyboard) or □⁄□Creates a fraction. The term you just typed jumps up onto the bar as the numerator (parenthesized groups are collected whole), and the cursor lands in the denominator.
^ (keyboard) or x■Opens a raised exponent box. x² / x³ / x⁻¹ insert the filled power and return the cursor to the baseline.
√□Inserts a radical; the sign stretches automatically over anything you build inside — even fraction-in-fraction stacks. SHIFT+√□ gives ∛; SHIFT+x■ gives the n-th root with an index slot.
Letters then (Typing sin tan ln logb ncr… followed by ( converts the letters into a live function with the cursor inside.

Moving around

  • ◀ ▶ walk through the structure — into a radical, across the radicand, out the other side.
  • ▲ ▼ hop between numerator and denominator, and between a root's index and radicand. ▼ also exits an exponent.
  • Click anywhere — on a character (cursor lands before/after depending on which half you click), on an empty dashed slot, or on a slot's padding — the cursor goes exactly there.
  • Backspace / DEL deletes leftward; at the edge of a structure it steps inside; deleting a fraction bar dissolves the structure but keeps its contents.
  • Ctrl+Z undoes (up to 80 steps). Ctrl+C with nothing selected copies the linear form. Pasting a linear expression like sqrt(10.39/(0.25*tan(720/(2*6))*6)) converts it into the stack automatically.
  • Enter = evaluate.

Keyboard / builds a stacked fraction; the keypad ÷ inserts a linear ÷ sign — exactly the distinction the real Casio makes between the fraction key and the divide key. Both compute identically.

4 · The Keypad & SHIFT / ALPHA System

The keypad mirrors the fx-300ES PLUS 2 faceplate. Every key can carry up to three functions:

  • Main label (white) — what the key does when pressed alone.
  • Gold legend above-left — the SHIFT function.
  • Red legend above-right — the ALPHA function (mostly the A–F registers).

SHIFT and ALPHA are one-shot prefix keys: press one (its badge lights and the key outlines), press the target key, and the modifier clears itself. Pressing it again cancels. hyp works the same way as a prefix for the trig keys: hyp → sin gives sinh, and hyp → SHIFT → tan gives tanh⁻¹.

The circular replay D-pad navigates the equation (◀▶ through the structure, ▲▼ between stacked levels). On an empty screen, ▲ recalls your previous calculation for editing — the classic Casio replay.

7 · Behavior After Pressing =

The Scientific Calculator follows these entry rules:

  • Digit or function → starts a fresh calculation.
  • Operator (+ − × ÷ ^ % !) → continues from Ans: after 2+2=, pressing +3= gives 7.
  • Fraction key → the answer becomes the numerator.
  • ◀ or click → edit the expression you just evaluated.
  • ▲ on an empty screen → replay: recalls the last entry.

9 · History Tape & STAT Data Panel

History tape (right panel): every evaluated calculation is kept, rendered as a mini stacked equation with its result, and persists between sessions on the website. Click any entry to reload it into the editor for modification. Ans always holds the most recent result.

STAT panel (below the tape, or SHIFT+1): paste data — one value per line or comma-separated — and press Compute stats for n, x̄, s (sample), σ (population), Σx, Σx², min / Q1 / median / Q3 / max. Select X,Y pairs explicitly and paste at least three pairs (one pair per line) for linear regression: slope b, intercept a, r, and r² — the calculator's equivalent of the Casio STAT mode, with paste instead of one-at-a-time entry.

10 · Distributions Tab

Pick a distribution, set its parameters, and ask either question:

  • Given x → probability — enter a value; get the PDF/PMF, left tail P(X ≤ x), right tail P(X ≥ x), the equal-tail two-tailed probability, or P(a ≤ X ≤ b) in Between mode.
  • Given probability → x — enter α or a central probability; get critical values (z₀.₀₂₅ = 1.959964, t-table values, χ² and F criticals) or a central interval.

The plot shades the selected region in amber, labels the boundary values on the axis, prints the shaded probability, and marks the mean with a dashed teal line. Discrete distributions (Binomial, Poisson, Geometric, Negative Binomial, Hypergeometric) draw as bars with the included bars shaded — and the right tail is computed inclusively, P(X ≥ k), as it should be for counts.

Discrete x inputs must be integers; distribution count parameters must also be integers and satisfy their domain. Uniform bounds require lower < upper. Two-tail mode is disabled for discrete distributions because equal tail regions cannot generally match the requested probability. In inverse discrete mode, the selected quantile is the smallest integer with CDF at least the target; the actual inclusive region probability is displayed separately and may differ from the requested value.

Reliability distributions

For Exponential, Weibull, Lognormal, and Gamma, the results panel adds R(t) survival probability, hazard rate h(t), and MTBF. Weibull results include the β interpretation (β < 1 infant mortality, β = 1 random failures, β > 1 wear-out) plus B10 life, and a reminder that F(η) = 63.2% always.

11 · Hypothesis Tests Tab

Ten presets: 1- and 2-sample z (known population standard deviations), 1-sample t, 2-sample t (Welch and pooled), paired t, 1- and 2-proportion z, χ² for one variance, and F for two variances. Enter the summary statistics, choose the alternative (≠, <, >) and α, and run. You get the test statistic, p-value, critical value(s), and a plain-language decision — plus a plot of the reference distribution with the rejection region shaded and your statistic drawn as a red line. If the red line lands in the amber region, the result is significant at your α.

All fields are checked before calculation. Sample sizes and success counts must be whole numbers, standard deviations positive, and success counts no larger than their sample sizes. Changing a field, test or alternative clears previous results. Two-sided (1 − α) intervals accompany the tests, even when the selected hypothesis test is one-sided. Proportion intervals use the Wald approximation and can perform poorly near 0 or 1; sparse expected counts trigger a normal-approximation caution.

For the asymmetric χ² and F distributions, two-tailed p-values use the equal-tail-probability convention, matching Minitab.

Example — did the process mean shift? x̄ = 52, s = 4, n = 25, target μ₀ = 50
Test: 1-sample t · Alternative: ≠ · α = 0.05
t = 2.50, df = 24, p = 0.0197 < 0.05 → Reject H₀ — the statistic falls in the shaded region beyond t₀.₀₂₅,₂₄ = ±2.0639

13 · Accuracy Notes

The legacy distribution engine uses incomplete gamma/beta functions and numerical inversion. Tiny upper tails are evaluated directly where supported. New numerical and interface tests cover known matrix, probability, calculus, finance, control-chart, regression and ANOVA cases. This is targeted validation, not a guarantee of uniform precision across every input. IEEE double precision and displayed rounding can affect extreme cases; a numerical failure or undefined statistic must not be treated as evidence about a process.

14 · Data & Quality

Choose an analysis before pasting data. Load example supplies a complete working dataset. Analyze data replaces the results; changing data or settings invalidates the previous results and disables exports.

AnalysisInput formatOutputs and interpretation
Descriptive statisticsAny arrangement of numeric cells, combined into one sample; minimum two values.Mean, sample and population standard deviations, standard error, quartiles, sum, sum of squares, t confidence interval, histogram, box plot and normal probability plot. Quartiles use linear interpolation (Excel PERCENTILE.INC).
Linear regressionExactly X,Y per row; at least three pairs.Slope, intercept, Pearson r, R², residual standard error (n − 2 denominator), RMSE (n denominator), two-sided slope p-value, slope interval, fitted values and residual plot. Constant X is rejected; constant Y makes r and R² undefined.
Quadratic, cubic, quarticX,Y pairs; at least degree + 2 observations and sufficient distinct X values.Coefficients are displayed in original X units. Calculation uses centered and scaled X; ill-conditioned inputs are rejected. A line connects fitted values at supplied X values.
Logarithmic, exponential, powerX,Y pairs. Logarithmic/power require positive X; exponential/power require positive Y.Logarithmic: a + b ln(X). Exponential: a exp(bX). Power: aXᵇ. Exponential/power fit ln(Y), without retransformation bias correction. R² and RMSE are reported on the original Y scale.
One-way ANOVAOne group per row; at least two groups and two values per group. Unequal group sizes are supported.Classical equal-variance F test, ANOVA table, group summaries and eta-squared. A significant result means at least one mean differs; it does not identify the differing pairs.
Chi-square independenceA rectangular table of nonnegative whole counts, at least 2 × 2. Exclude row/column totals.Pearson χ², approximate p-value, df, Cramér’s V, expected frequencies and cell contributions. No Yates correction. Expected counts below 5 trigger a caution.
Chi-square goodness of fitExactly two rows: observed counts, then expected counts. Positive expected counts; equal totals.Pearson χ² and df = categories − 1. Expected proportions must be specified independently. Adjusted df for parameters estimated from these data are not implemented.

Numbers may be separated by tabs, commas, semicolons or spaces. Use a period for the decimal point and omit headers, units, thousands separators and totals. Scientific notation such as 1.2e-3 is accepted. Blank lines are ignored, but empty cells and malformed values are rejected with their row and cell number. Data entry is limited to 10,000 values, 250,000 characters and magnitude 10¹⁰⁰.

One-way ANOVA worked example
6.9,5.4,5.8,4.6,4.0
8.3,6.8,7.8,9.2,6.5
8.0,10.5,8.1,6.9,9.3

Assumptions: mean intervals and regression inference require independent observations with suitable distributional assumptions. ANOVA assumes approximately normal errors and common population variance. Chi-square tests require independent counts in mutually exclusive categories. A large p-value does not prove equality or independence.

15 · Capability & I-MR Charts

  1. Choose Capability & I-MR, then paste individual measurements in time order.
  2. Enter the lower and/or upper engineering specification. A two-sided specification requires LSL < USL.
  3. Review the I-MR plots and flagged observation numbers before interpreting capability.
  4. Compare observed out-of-specification counts with the separate normal-model estimate.
MeasureCalculation / meaning
Overall sSample standard deviation, using n − 1.
Within sigmaMean absolute difference between consecutive observations divided by 1.128.
Pp / PpkSpread / centering relative to specifications, using overall s.
Cp / CpkSpread / centering relative to specifications, using the moving-range sigma estimate.
Spread index(USL − LSL) ÷ (6 × sigma); requires two limits.
Centering indexSmaller of (USL − mean) ÷ (3 × sigma) and (mean − LSL) ÷ (3 × sigma). For one limit, use the available side.
I-chart limitsMean ± 3 × within sigma.
MR-chart limitsLower 0; center MR̄; upper 3.267 × MR̄.

Only points beyond the limits are flagged. Other run rules are not tested. No flags does not prove stability. The same data estimate the limits and populate the chart. Autocorrelation, mixed populations, small samples and non-normality can invalidate capability interpretations. Specification limits are engineering requirements; control limits describe process behavior. Values exactly on specification limits count as conforming.

Normal-model PPM uses the sample mean and overall s without a 1.5-sigma shift. It is not the observed defect rate. Zero variation is rejected; a very small sample cannot justify a confident capability claim.

Mean 50.81; MR̄ 1.8777778; I-chart limits 45.8159102 and 55.8040898. This example contains only ten observations and is for learning the calculation.

18 · Finance & Amortization

  1. Select the unknown: N, annual nominal I%, PV, PMT or FV. Its input is disabled and ignored.
  2. Enter the known values, payments per year, compounds per year, and beginning/end payment timing.
  3. Use positive amounts for cash received and negative amounts for cash paid.
  4. Press Solve TVM. For a positive principal and negative payment with an integer N ≤ 600, an amortization table is also displayed.

N counts payments, not years. If r is the effective rate per payment period, r = (1 + I% ÷ (100 × C/Y))^(C/Y ÷ P/Y) − 1. The solver uses PV(1+r)ᴺ + PMT × annuity factor + FV = 0, with the payment factor multiplied by (1+r) for beginning-of-period payments. At zero interest, the annuity factor is N.

Five-year loan example
N = 60, annual I% = 6, PV = 20,000, FV = 0, P/Y = C/Y = 12, end-of-period payments → PMT ≈ −386.656030589.

In Lists & Matrices, npv(0.1,[-1000,400,400,400]) gives −5.25920360631. The first cash flow is at time zero; the rate is a decimal per period. irr([-1000,400,400,400],0,1) finds a periodic IRR of about 0.0970102574 within the bracket [0,1]. IRR may have multiple solutions or none. The TVM rate search is limited to annual nominal rates from −90% to 1,000%; N is bracketed from 0 to 100,000. These searches can fail for valid cases outside those ranges.

eff(6,12) returns the annual effective percentage for 6% nominal compounded monthly. nom(effectivePercent,compoundsPerYear) reverses the conversion. Amortization uses unrounded internal cash flows; lender rounding, fees and payment conventions can differ.

19 · Calculation Programs

The program editor supports a deliberately limited, documented command language. It is not a complete TI-BASIC interpreter and does not load tokenized calculator files. Programs share session variables with the math workspace. Download source preserves the text for later reuse.

0→S
For(I,1,10)
  S+I→S
End
Disp S

This example prints 55. Supported commands are assignments with →, -> or =; Disp expression; ClrHome; For; While; If / Then / Else / End; and Stop. Every control block needs End. Conditions support comparisons and Boolean operators; a single = in an If/While condition means equality. Maximum: 500 lines, 10,000 execution steps and 1,000 output lines, plus the worker time limit.

Not supported: Goto/Lbl, interactive Input/Prompt/Menu, key scanning, drawing commands, list indexing, strings with TI-specific token semantics, assembly, hardware calls, .8xp imports, or installed TI applications. Unsupported statements produce errors; they are not silently skipped.

21 · Exports, Privacy & Troubleshooting

Data & Quality exports a text report with inputs, settings, metrics, tables and assumptions, plus a CSV results file. The graph exports SVG; the math tape and program source export text. Calculations run locally; these workspaces do not upload datasets or program source. The Scientific Calculator’s history continues to use browser local storage. Other session variables and analysis inputs are not automatically saved. Download anything you want to retain before reloading.

  • Invalid data: use the reported row/cell; remove headers and units, correct empty cells, and select the intended analysis.
  • Old result disappeared: the input changed. Recalculate to create results for the current inputs.
  • Worker timeout: reduce the expression/program size. The worker resets and shared variables must be re-entered.
  • Graph gaps: inspect domain restrictions and singularities. Increase the window or evaluate the function numerically.
  • Unsupported command: search the supported catalog. TI syntax is not automatically translated.
  • Downloads: allow normal file downloads for this site. Export buttons for analysis remain disabled until calculation succeeds.
