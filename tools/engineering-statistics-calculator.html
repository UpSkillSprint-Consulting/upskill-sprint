Project inputs

1 · Quality cost ledger

Enter the headers below. Categories: Prevention, Appraisal, Internal failure, External failure. Line cost = Quantity × UnitCost. Use quantities such as scrap tonnes or rework/downtime hours and matching rates. Events are separately allocated counts, not quantities.

2 · Production volume & revenue

One row per period/product. Positive volume in one consistent production unit. Blank revenue means unknown; zero means zero. Periods follow table order. A baseline rate for each product adjusts comparisons to the current volume and product mix.

Import from Guided Analysis

Import Excel/CSV there first. Rename/reorder the columns to exactly match the target table headers. Explicit exclusions and the exact category filter apply. This copies a snapshot, with provenance in the report.

Directly entered tables.

3 · Projected improvement business case

Standalone annual forecast, not calculated or verified from the cost reduction. Year 0 implementation outlay; constant annual benefits/costs over the horizon. Only cash savings enter cash NPV, ROI and payback.

Low/base/high scenarios vary gross cash benefit only; costs stay fixed. Use a rate consistent with your nominal/real cash-flow basis. No tax, inflation, terminal value or borrowing model is applied.

4 · Benefit & cost verification register

Optional. Types: Cash savings, Cost avoidance, Released capacity, Implementation cost, Recurring cost. Status: Projected, Realized, Verified. Keep one unique ID per benefit/cost and update its status; do not duplicate it across stages. Amounts are period totals in the selected currency; capacity is a noncash valuation.

Verified entries require an owner, evidence reference, valid nonfuture date (YYYY-MM-DD) and basis/verification notes. Negative benefit amounts record reversals; cost amounts must be nonnegative. Verification is user-recorded, not authenticated or approved by this tool.

Session-only, local calculations. Up to 2,000 rows / 1 MB per table. Save before closing. Do not add ledger cost reductions, forecasts and register benefits together.

Separate columns with commas, tabs or spaces. Up to 10,000 values and 250,000 characters. Missing cells are rejected; blank lines are ignored. Preserve chronological order.

Pasted measurements

Only these first rows estimate limits. Later rows are monitoring observations. Include at least 20 representative baseline rows when possible.

No frozen baseline. Estimate from the first rows.

Freezing keeps only the later monitoring rows in the editor; baseline data remain in the snapshot. With a frozen baseline, paste the complete monitoring sequence each time. Save before closing; there is no automatic storage.

Files stay in this browser. Up to 10 MB per file; 10,000 rows, 40 columns and 100,000 cells per dataset. Use a period for decimals. Older .xls files must be saved as .xlsx or CSV.

Review and edit data · row exclusions & import notes

Edit cells directly. Uncheck a row to exclude it explicitly; changing data invalidates results. Row order is preserved. Duplicate rows are flagged for review and retained.

Dataset edit history

Datasets are held in memory for this session. Save workspace to keep data, edits, exclusions and analysis settings before reloading. Restoring a project adds its datasets; it never runs an analysis automatically.

2 · Define your question

For two groups, difference = comparison minus reference. With three or more groups, ANOVA tests for any mean difference.

Choose this threshold before reviewing results. All t tests use two-sided inference.

Filter rows and handle missing values

Only blanks in the selected analysis columns are treated as missing. Invalid numbers block analysis. Paired rows are excluded together.

Guidance follows your question and study design. It does not automatically certify assumptions or choose a method using a normality-test p-value.

    Methods, assumptions & references

    Intervals for a mean use Student’s t. Regression fits ordinary least squares with an intercept; residual standard error uses n − 2 degrees of freedom. ANOVA is the classical equal-variance F test. Chi-square uses Pearson’s statistic without continuity correction and reports every expected cell count.

    Capability uses s for Pp/Ppk and MR̄ ÷ 1.128 for Cp/Cpk. I-MR limits are estimated from the entered sequence; only points beyond three-sigma limits are flagged. Review stability, independence and distribution shape before interpreting capability. Specification limits are engineering requirements, not control limits.

    • NIST: Individuals control charts
    • NIST: Process capability
    • NIST: One-way ANOVA
    • Penn State: Chi-square independence

    Math workspace
    Lists: L1 = [1,2,3]. Matrices: A = [1,2;3,4]. Complex: sqrt(-1), (2+3i)*(1-i). Units: 25.4 mm to inch. Last result: Ans. Variables are shared with graphing and programs for this session.
    Calculation tape
    Evaluate expressions using the examples or function catalog.
    Syntax & numerical tools
    Use * for multiplication and ^ for powers. ln(x) and log(x) are natural logarithms; log10(x) is base 10. Complex results use a + bi. arg(z) returns radians. RAD/DEG applies to trigonometric functions, their inverses, atan2, and the nDeriv/fnInt/solve/seq helpers. Complex arg/angle remains in radians.
    nDeriv("x^3",2), fnInt("sin(x)",0,pi), solve("x^2-2",0,2), seq("n^2",1,10), rref([1,2,3;2,1,4]).
    Matrix/list indexing and user-defined functions are not enabled. Use whole-array operations. Large operations are bounded; a timeout resets workspace variables to keep the interface responsive.
    

    Time value of money
    Money received is positive; money paid is negative. N counts payment periods, not years. The selected unknown is ignored until solved.
    Financial results
    Cash flows & rate conversion
    In Lists & Matrices, use npv(0.10,[-1000,400,400,400]) for a 10% per-period discount rate. The first cash flow occurs at time zero. Use irr([-1000,400,400,400],0,1) for the decimal periodic IRR within a bracket. IRR can have multiple roots or no root.
    eff(6,12) converts 6% annual nominal interest, compounded monthly, into an annual effective percentage. nom(6.1678,12) performs the reverse conversion. TVM uses an annual nominal percentage; NPV/IRR use decimal rates per cash-flow period.
    

    Calculation programs
    Programs run locally in an isolated worker. Maximum 500 lines and 10,000 execution steps. A timeout resets shared variables.
    Program output
    Supported programming subset
    Assignments (value→A, value->A, or A=value), Disp expression, ClrHome, For(I,start,end,step), While condition, If condition / Then / Else / End, and Stop. Every control block requires End, including If.
    Use the math-workspace function catalog. This is a documented calculation-language subset, not a TI-BASIC emulator: device I/O, key events, labels/Goto, graphical commands, tokenized .8xp files and installed TI apps are not supported.
