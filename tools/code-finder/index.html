Code Finder: look up the codes and standards that apply

Type what you are working on in plain words, or filter by industry, category and task. Code Finder searches API, CSA, ASTM and ISO codes and shows how they connect.

Works with code numbers (5L, Z245.1, A370) and shop-floor words (CVN, MTR, gauge R&R).

    Before you rely on a code

    Code Finder lists facts about each code (number, title, scope in our own words, links) and never the code text itself. Editions change and regulators adopt specific editions. Always confirm the current edition with the publisher and check which edition your regulator or contract calls for. Cards marked Not yet checked have not been confirmed against the publisher's catalog.
